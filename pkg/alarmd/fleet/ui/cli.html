浏览器和 CLI 不在同一台机器？改用复制授权码

先完成上面第 2 步核对环境，再生成授权码。





在 CLI 所在机器的终端运行 alarmd-cli auth login，按提示粘贴下方授权码。授权码 5 分钟内有效且仅能兑换一次；不要放入聊天记录、工单或命令参数。












会话有效期与撤销授权

会话有效期 1 小时，到期由 CLI 用续期凭据自动换新；续期凭据每用一次换一个。闲置 30 天或被撤销后才需要重新配对。


撤销本机的配对：在终端执行 alarmd-cli auth logout --env 环境ID。


撤销本环境全部 CLI 授权：所有已配对的 CLI 都要重新配对；管理凭据轮换后，旧的配对也会自动失效。需要先完成上面第 2 步核对环境。
